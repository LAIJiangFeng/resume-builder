# 移动端编辑页布局与模块拖拽修复

## 1. 背景

移动端简历编辑页存在多个可见交互问题：底部菜单栏按钮整体靠左而非居中分布，顶部提示图标没有贴近“基本信息”标题，提示框在移动端超出屏幕边界，模块区域内的模块无法拖拽移动。

## 2. 目标

修复移动端编辑页的底部导航居中、标题提示图标对齐、提示框屏幕内展示和模块拖拽排序能力，保持当前页面整体风格与业务结构不变。

## 3. 范围

- 移动端简历编辑页底部导航样式。
- 移动端“基本信息”标题与提示图标布局。
- 移动端本地存储提示框宽度与定位。
- 编辑页模块列表拖拽排序交互。
- 必要的前端验证与浏览器交互核对。

## 4. 非目标

- 不重做整体视觉风格。
- 不新增页面、接口或后端能力。
- 不新增或修改测试代码、测试脚本、fixture 或 mock。
- 不调整简历模板渲染与 PDF 导出逻辑。

## 9. 二次修复：移动端模块拖拽兜底

### 9.1 背景

用户反馈移动端简历编辑区域仍无法拖拽模块。复查当前实现发现，模块抽屉已有触摸 Pointer 拖拽逻辑，但移动端调试视口下使用鼠标拖动“拖拽”手柄不会改变模块顺序，且移动端拖拽过程过度依赖手柄自身的 pointer capture，容错不足。

### 9.2 目标

在不重做 UI、不改变模块开关和基础信息不可拖拽规则的前提下，补强模块抽屉的拖拽手柄交互，让触摸拖拽和移动端视口鼠标拖拽都能稳定改变模块顺序。

### 9.3 非目标

- 不调整简历编辑页整体视觉布局。
- 不新增接口、后端能力或测试代码。
- 不改变模块开关、搜索、展开收起和基础信息固定首位规则。

### 9.4 细化任务清单

- [已完成] 复查当前移动端模块拖拽事件链路和失败路径。
- [已完成] 补强拖拽手柄的 Pointer 事件处理，覆盖触摸与移动端视口鼠标拖动。
- [已完成] 保持基础信息模块不可拖拽，模块开关点击不受影响。
- [已完成] 执行允许范围内的验证并记录结果。

### 9.5 验收细节 list

- [通过] 基础信息模块仍保持首位且没有拖拽手柄。
- [通过] 模块开关点击仍只切换启用状态，不触发拖拽排序。
- [通过] 允许范围内的前端验证命令完成，或明确记录未执行原因。
