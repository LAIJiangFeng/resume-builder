# 登录界面 Stitch 现代化重设计

## 1. 背景

当前任务要求使用 Stitch 重新设计登录界面，并明确不沿用既有旧风格、不使用项目中的 UI Skills。现有 Stitch 登录设计偏深色金色玻璃拟态，本轮需要创建独立视觉方向，避免旧主题影响。

## 2. 目标

1. 使用 Stitch 生成一版现代、专业、无明显 AI 味的 Web 登录界面。
2. 建立独立设计系统，避免复用旧暗金玻璃拟态风格。
3. 使用真实图标体系或第三方图标风格，不使用 emoji 表情。
4. 通过批判性检查持续完善设计，直到符合现代 Web 登录界面的专业规范。

## 3. 范围

1. 新建 Stitch 项目承载本次登录界面设计。
2. 新建设计系统，定义色彩、字体、间距、形状、组件和图标风格。
3. 生成桌面登录界面屏幕。
4. 对生成结果进行批判性检查，并按问题继续迭代。

## 4. 非目标

1. 不修改当前仓库登录页面代码。
2. 不新增或修改测试代码、测试脚本、fixture 或 mock 文件。
3. 不沿用现有暗金玻璃拟态设计系统。
4. 不使用项目 UI Skills。
