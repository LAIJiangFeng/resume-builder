# 登录界面 Pen 现代化重设计

## 1. 背景

当前登录页已经具备基础中文登录表单、演示账号入口和线性图标，但视觉仍偏暖色产品展示稿，左侧简历编辑预览信息量较重，登录本体不够聚焦。本轮按用户要求，不使用项目中的 UI Skills，以 `.pen` 设计稿重新输出现代 Web 登录界面。

## 2. 目标

1. 生成一版现代、克制、专业的中文 Web 登录界面设计稿。
2. 登录设计不沿用旧暖色青绿风格，不出现明显 AI 模板感。
3. 使用真实第三方线性图标，不使用 emoji 表情。
4. 字体采用轻量中文字体体系，避免标题和控件过重。
5. 通过批判性复查迭代设计稿，直到符合现代登录页规范。

## 3. 范围

1. 观察当前登录页视觉风格。
2. 在 `.pen` 中新增登录页设计画板。
3. 设计桌面端与移动端登录界面。
4. 导出设计截图进行视觉验收。

## 4. 非目标

1. 不修改现有登录代码、认证接口或路由逻辑。
2. 不新增或修改测试代码。
3. 不沿用项目 UI Skills。
4. 不引入第三方登录流程实现。
