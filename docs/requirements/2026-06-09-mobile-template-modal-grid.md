# 移动端模板选择弹窗多列适配

## 1. 背景

移动端实时预览区域打开模板选择弹窗时，模板预览卡片在小屏断点下会退化成单列，导致单个模板占用高度过大，用户需要长距离滚动才能浏览多个模板。

## 2. 目标

让模板选择弹窗内的模板卡片在移动端根据屏幕宽度自动缩小，并尽量保持多列展示，提升小屏浏览效率。

## 3. 范围

- 调整 `src/components/resume/TemplatePickerDialog.vue` 中移动端模板列表网格和卡片尺寸。
- 保留现有弹窗结构、模板选择逻辑、配色和交互状态。
- 完成允许范围内的前端验证与浏览器级视觉检查。

## 4. 非目标

- 不重做模板选择弹窗整体视觉风格。
- 不修改简历模板预览图资源。
- 不修改简历模板注册、选择、PDF 导出或持久化逻辑。
- 不新增或修改任何测试代码。

## 5. 细化任务清单

- [x] 定位移动端模板选择弹窗一列显示的样式来源。
- [x] 将移动端模板列表调整为可缩小的自适应多列网格。
- [x] 压缩移动端卡片内边距、标题和标记尺寸，避免多列展示时拥挤。
- [x] 执行允许的前端验证并记录结果。
- [x] 使用浏览器级工具检查移动端弹窗展示效果。
