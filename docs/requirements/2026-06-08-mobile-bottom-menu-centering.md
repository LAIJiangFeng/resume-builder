# 移动端底部菜单居中修复

## 1. 背景

普通用户移动端只显示 3 个底部菜单项时，底部菜单仍按 4 列网格布局渲染，导致 3 个菜单项占据前 3 列，整体视觉偏左，没有在底部栏内居中分布。

## 2. 目标

1. 移动端底部菜单按实际可见菜单数量分列。
2. 普通用户 3 个菜单项时在底部栏内居中分布。
3. 管理员 4 个菜单项时保持原有四项分布。

## 3. 范围

1. 侧边栏组件的移动端菜单布局。
2. 移动端菜单项数量变化时的网格列数。
3. 前端允许范围内的静态验证和浏览器级验证。

## 4. 非目标

1. 不调整底部菜单的业务入口和权限规则。
2. 不重做底部菜单视觉风格。
3. 不调整简历编辑页面内容区布局。
4. 不新增或修改测试代码、测试脚本、fixture 或 mock 文件。

## 5. 细化任务清单

- [已完成] 定位 3 个菜单项时底部菜单偏左的样式原因。
- [已完成] 将移动端底部菜单列数改为按实际可见菜单数量计算。
- [已完成] 保持管理员 4 项菜单布局不回退。
- [已完成] 执行允许范围内的验证并记录结果。

- [通过] 管理员移动端底部菜单仍显示 4 个菜单项并均分底栏宽度。
