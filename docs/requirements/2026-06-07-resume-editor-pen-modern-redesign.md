# 简历编辑界面 Pen 现代化重设计

## 1. 背景

用户要求参考上一轮登录设计提示词和新登录设计风格，结合当前简历编辑界面的真实功能，重新设计简历编辑界面。当前真实界面功能完整，但视觉仍偏暖米色后台风，左侧菜单、编辑区、预览区和浮动 AI 按钮层级竞争明显，本轮只输出 `.pen` 设计稿，不修改前端业务代码。

## 2. 目标

1. 以冷白纸面、墨蓝结构、钴蓝主操作和轻量中文字体延续新登录设计风格。
2. 保留当前简历编辑核心功能：模块编辑、模块开关/排序、完整度、自动保存、导入 JSON、保存草稿、实时预览、模板切换、导出 PDF/Markdown/JSON、AI 优化入口。
3. 重新建立“编辑主流程 + A4 预览事实 + AI 辅助”的工作台层级。
4. 输出桌面端、移动端和批判性复查画板。

## 3. 范围

1. 观察当前简历编辑界面和相关源码结构。
2. 生成现代简历编辑工作台桌面端设计稿。
3. 生成移动端简历编辑界面设计稿。
4. 导出设计截图并做布局检查。

## 4. 非目标

1. 不修改 `src/` 下真实前端代码。
2. 不修改认证、导出、模板、AI 优化等业务逻辑。
3. 不新增或修改测试代码。
4. 不使用项目 UI Skills。

- [x] 新增现代简历编辑工作台移动端设计画板。
- [x] 新增批判性复查画板并完成必要修正。

- [通过] 设计风格与新登录 Pen 稿一致，不沿用当前暖米色后台风。
- [通过] 桌面端保留并清晰表达模块编辑、模块开关/排序、完整度、保存、导入、预览、模板切换、导出和 AI 优化入口。
- [通过] 移动端采用单列/分段结构，不强塞桌面三栏，触控控件不低于 44px。
- [通过] 图标使用真实线性图标，不使用 emoji。
- [通过] 批判性复查覆盖旧风格剔除、功能保留、主次层级、移动端密度和 AI 辅助边界。
