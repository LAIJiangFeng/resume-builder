# 暗黑登录界面 Stitch 中文化微调

## 1. 背景

用户要求采用已经生成的暗黑登录界面，不继续使用浅色纯净版，并在暗黑稿基础上去除 Google / GitHub 登录，同时把英文文案改为中文。用户后续提供截图，明确目标为深蓝黑网格背景、左侧 `Professional Narrative`、右侧 `回到你的简历工作台` 的暗色稿。

## 2. 目标

1. 基于已有暗黑 / 黑蓝色 Stitch 登录界面生成新的中文交付版。
2. 移除 Google 登录、GitHub 登录及相关第三方登录分隔文案。
3. 保留账号密码登录、记住状态、忘记密码和注册入口。
4. 保持原暗黑界面的视觉结构、深蓝黑背景和专业控制台气质。

## 3. 范围

1. 使用已有 Stitch 项目 `projects/1740873361760139533`。
2. 以用户截图对应的暗色网格屏幕 `projects/1740873361760139533/screens/8a1997dcd62a48aaa6f91acdfeebb5fd` 作为基稿。
3. 生成新的 Stitch 屏幕作为交付稿。
4. 检查 HTML 和截图，确认第三方登录入口已移除且主要英文文案已中文化。

## 4. 非目标

1. 不修改认证接口、登录状态管理和登录成功后的业务路由。
2. 不新增或修改测试代码、测试脚本、fixture 或 mock 文件。
3. 不重新设计为浅色界面。
4. 不引入新的第三方登录方式。
