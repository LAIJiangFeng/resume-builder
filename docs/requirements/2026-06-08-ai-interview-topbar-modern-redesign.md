# AI 面试顶部布局现代化重设计

## 1. 背景

AI 面试页顶部区域需要从旧式控件堆叠调整为更现代、克制、专业的顶部布局组件。用户明确要求不使用项目内 UI 类 skill，不添加多余描述，不使用 emoji，图标可使用第三方图标库。

## 2. 目标

重设计 AI 面试页顶部 header 的布局、图标、控件层级和响应式样式，使其更符合现代 Web 顶部组件规范，并保留现有历史会话、刷新、状态展示能力。

## 3. 范围

- 调整 `src/components/ai/interview/AiInterviewerPanel.vue` 顶部 header 的模板结构。
- 调整顶部 header 相关样式，包括桌面与移动端适配。
- 使用项目已有 `lucide-vue-next` 图标库，不新增依赖。

## 4. 非目标

- 不修改 AI 面试接口、会话逻辑、语音逻辑和评分逻辑。
- 不重构面试主体聊天区、右侧控制台和浮动控制台。
- 不新增测试代码、测试脚本、fixture 或 mock 文件。
- 不使用项目内 UI 类 skill。

## 5. 细化任务清单

- [x] 任务 1：确认顶部现有结构、依赖与第三方图标使用方式。
- [x] 任务 2：重构顶部 header 信息层级，保留必要业务信息并移除旧式裸控件感。
- [x] 任务 3：补齐桌面与移动端响应式样式，避免顶部控件溢出。
- [x] 任务 4：执行允许的前端验证并记录结果。
