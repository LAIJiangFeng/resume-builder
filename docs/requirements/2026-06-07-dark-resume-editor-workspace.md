# 暗黑简历编辑工作台主题化改造

## 任务背景

用户已在 Stitch 中确认“ResumeFlow 简历编辑工作台 - 功能覆盖完整版”作为最终稿，需要把简历编辑区域改成更专业的暗黑工作台风格，并为后续设置页一键切换主题风格沉淀基础。

## 目标

1. 参考最终稿，把简历编辑区域调整为暗黑专业风格，保留顶部栏、侧边菜单、信息编辑区、实时预览区的工作台结构。
2. 将本次暗黑主题颜色沉淀到独立 CSS 文件中，后续可集中维护主题色。
3. 设置页提供主题风格选择入口，当前至少支持一键选择暗黑工作台风格。
4. 保留现有功能能力：AI 优化、模块显示隐藏与排序、导入 JSON、切换模板、导出高清 PDF / 压缩 PDF / Markdown / JSON 进度。

## 范围

1. 前端全局主题变量与页面样式。
2. 简历编辑面板、实时预览面板和设置页主题选择区域。
3. 必要的 App 主题状态接入。

## 非目标

1. 不新增后端接口、数据库表或权限模型。
2. 不新增测试代码、测试脚本、fixture 或 mock。
3. 不重写简历导出、AI 优化、模板渲染或模块排序业务逻辑。
4. 不引入新的 UI 组件库。
