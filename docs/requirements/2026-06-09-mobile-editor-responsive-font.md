# 移动端编辑区字体自适配

## 1. 背景

用户在移动端编辑简历时，编辑区表单内已填写文字字号过大，和屏幕宽度、输入框空间不匹配，影响基本信息等字段的填写观感。

## 2. 目标

让移动端简历编辑区的填写字号随屏幕宽度自适配，提升小屏表单可读性和空间利用率。

## 3. 范围

- 简历编辑区模块内容中的普通输入框、下拉框、文本域。
- 简历编辑区模块内容中的富文本编辑区域和占位文字。
- 仅处理移动端断点下的字号适配和必要行高。

## 4. 非目标

- 不调整桌面端编辑区布局。
- 不调整简历预览区字体。
- 不重做移动端页面结构、按钮样式、模块顺序或交互流程。
- 不新增或修改任何测试代码。

## 5. 细化任务清单

- [已完成] 修改移动端编辑区填写字号为响应式字号。
- [已完成] 执行允许范围内的前端验证。
